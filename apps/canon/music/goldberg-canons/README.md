# Goldberg canon resources

This directory contains the nine canonic variations from J. S. Bach's *Goldberg Variations*, BWV 988: variations 3, 6, 9, 12, 15, 18, 21, 24, and 27.

- `data/*-notes.json`, `data/*-align.json`, and `data/*-timeline.json` are derived from [The Canon Machine](https://canon.ppr3.com/), whose score and alignment data are based on the Open Goldberg Variations edition.
- `audio/*.mp3` contains browser-compatible, loudness-normalized excerpts from Kimiko Ishizaka's 2012 Open Goldberg Variations recording.
- `scores/*.musicxml` is a study arrangement generated by `scripts/generate_goldberg_scores.py`: leader, follower, and independent bass each have a separate staff. Variation 27 has only leader and follower. Original note pitches, timing and durations are retained; this is not the original piano grand-staff layout.

The Open Goldberg score and recording are released under [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Credit: Kimiko Ishizaka, MuseScore/Open Goldberg Variations, and Peter Repetti's Canon Machine alignment pipeline.

Variation 27 shares its source audio file with Variation 28. The player uses the alignment clip boundary and stops before Variation 28 begins.
